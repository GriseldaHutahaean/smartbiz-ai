# Semantic Search Benchmark

Run the benchmark after the vector environment is available:

```bash
uv run python scripts/vector_pipeline.py all --reset
```

The command writes these runtime artifacts into this folder:

- `semantic_search_benchmark.csv` - one row per query with Top-K, similarity,
  Precision@K, Recall@K, acceptance, false acceptance, and false rejection.
- `semantic_search_benchmark.json` - full retrieved chunks and threshold.
- `semantic_search_benchmark.md` - human-readable analysis.
- `semantic_search_benchmark.png` - Top-1 similarity plot with threshold.

The benchmark labels expected relevance by source document and includes
relevant, synonym, ambiguous, and out-of-domain queries. Scores must be
generated by an actual ChromaDB query; no static example scores are committed.
